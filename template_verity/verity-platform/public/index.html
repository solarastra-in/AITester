How it works

Five steps, the same for every project

01
Give it a URL
Create a project and point it at the site you want tested — staging, production, an internal tool, anything reachable over HTTP.
02
Upload or generate test cases
Bring your own test plan (structured JSON/CSV, or a Markdown table — even a messy one) or hand the URL and a description to an AI generator using your own model key.
03
It asks for what it's missing
Every test declares the dataset fields it needs — auth tokens, sample records, provider keys. The console surfaces exactly those fields so you're never guessing what to fill in.
04
Run it — free preview or hosted
Real HTTP and load-test execution against your real endpoint. Run a capped free preview in-console, or pay per hosted execution when you want it off your own infrastructure.
05
Take it anywhere
Download a self-contained Docker package — your exact suite and dataset baked in — with deploy instructions for AWS, GCP, Azure, or any VM. No lock-in.
